# 展示系列

主题的通用设计区域、可修改范围和固定边界见 [主题套件设计规范](theme-kit.md)。本文继续说明当前展示系列架构与咖啡的具体实现；其中的容器、堆积、等级和液体参数不构成所有主题的要求。

系列只解释真实专注记录，不创建独立积分余额，也不影响计时。用户只能在设置里选择已实现的系列，不能修改系列参数。当前仅提供咖啡豆，不展示钞票等占位选项。

## 套件模块边界

当前采用内置注册方式，不加载外部主题插件。每套主题实现五个区域，注册六个组件：专注小窗、休息小窗、休息符号、记录展示、单条记录标识、主题设置。入口契约独立于咖啡，具体步骤见 [主题套件设计规范](theme-kit.md)。

- `theme-kits/catalog.json`：前端、核心校验和原生菜单栏共用的内置主题名称、双外观配色、图标路径与选项 schema；`theme-kits/<id>/` 保存原生资源。
- `src/shared/series/types.ts` / `contracts.ts`：主题身份、通用配色及各区域输入契约。主题身份由清单键生成，不在多个页面重复枚举。
- `catalog.ts`：纯数据目录和未知编号兜底，不导入 Vue 组件或 Tauri。
- `registry.ts` / `renderers.ts`：通用组件选择和内置套件注册。不以 Coffee 组件类型约束其他套件。
- `SeriesReward.vue` / `SeriesCollection.vue`：标识和记录区域入口。记录展示分别收到范围内记录、完成归属记录和真实总时长，不强制一条记录对应一个物件。
- `coffee/`：咖啡专属豆堆、Worker、缓存、液面、设置、图标及历史罐实现。通用计时页面不导入这些实现，不要求未来主题复用堆积或液体。
- `period.ts`：真实完成记录的本地日／周取数，不负责物理和视觉。
- `options.ts` / 核心 `themes.rs`：选项默认值、旧字段兼容绑定、受 schema 约束的局部保存。新选项按主题命名空间保存，支持枚举、布尔和有上下界的数值；拒绝未知主题、未知字段、非法值和过期主题提交。
- `src-tauri/build.rs`：按清单编译打包菜单栏图标；原生绘制接收图标与颜色数据，不固定咖啡配色。

主题设置通过 shared/ipc → commands → runtime → storage 保存，使用权威状态合并，失败不报告成功。`visual_series` 保持原字段；旧检查点没有 `theme_options` 时默认为空。咖啡 `range` 由 schema 绑定已有 `bean_range`，读写同一份值，不另存重复副本；旧 `save_bean_range` 接口保留兼容。切换主题不改变历史记录、计时或其他主题的偏好。当前仍仅注册咖啡，不展示测试主题。

## 咖啡豆预设

| 本轮有效专注时长  | 等级   |
| ----------------- | ------ |
| 不足 16 分钟      | 浅烘   |
| 16 至不足 32 分钟 | 中浅烘 |
| 32 至不足 44 分钟 | 中烘   |
| 44 至不足 60 分钟 | 中深烘 |
| 60 分钟及以上     | 深烘   |

阈值参考 Sweet Maria’s City 10:40 → City+ 11:05 → Full City 11:30 → Full City+ 11:50 → Vienna 12:15 的发展段比例，再映射到 0–60 分钟并取整。它是产品展示规则，不是整炉烘焙的统一分钟标准。[原始烘焙记录](https://library.sweetmarias.com/using-sight-to-determine-degree-of-roast/)

- 每轮已保存专注获得一颗；新记录需有效专注满一分钟，既有短记录继续保留，进行中、休息和取消不计算。
- 小窗按本地当天或本周（周一至周日）的完成顺序展示物理豆堆。豆子保持放大的尺寸与原 SVG、烘焙配色，在同一个三维碰撞世界中逐颗落入，稳定后计算完整图形的上沿。最高只到开始按钮上沿附近（豆堆最高距底部 62 个逻辑像素）；下一颗使豆堆超过上限时，恢复上一组完整且有支撑的稳定布局，不硬裁豆子、不缩小、不增加纵深或密度。达到上限后豆堆保持不变，新增完成数量继续计入完整统计，时间、短句和顶部不添加背景衬底。缓存保留最多四组布局，封顶后复用已验证的记录前缀，新增尾部记录不再启动物理计算；展示前缀变化时重新计算，防止删除支撑豆后悬空。记录页罐子逻辑不变。
- 罐内目标容量约 80 颗，以共同三维碰撞世界的实际容积决定；所有豆子从罐口上方落入，不按编号预先指定哪些记录溢出。满后由求解结果确定罐外记录，再使用已确认的低矮堆积构图安排外部展示。
- 保留原有 SVG 图形和烘焙配色，将三维位置、朝向投影为简洁插画。按深度排序，区分玻璃内、罐后与罐前，配合轻微接触阴影和玻璃遮挡。每条完成记录只绘制一颗豆。
- 罐外构图由 `compactOverflow.ts` 与 `ExteriorBean.vue` 负责，保持原 SVG、记录身份与烘焙颜色；以豆子长轴控制朝向和厚度，明确排列遮挡顺序，不修改罐内姿态。
- 收集区整体最多展示最先完成的 120 颗，达到上限后几何保持饱和；完整历史、数量与时长继续累计。
- 罐子和取景比例不随数量变化；溢出可超出展示区，在窗口边界裁切，不引入横向滚动。Worker 后台求解，稳定后一次性显示，不播放下落；完成后释放 Worker 和物理世界。有限内存缓存只保存几何，不保存任务标题、颜色或时长。
- Bean SVG geometry 与 cannon-es 许可位于 `public/licenses/`。

## 开发预览与测试数据

先按项目规则检查已有服务，再使用 `npm run dev`。打开开发地址后添加 `?dev=series&gallery=1`，显示 20、40、80、110、120 颗的实际组件对照；`?dev=series&count=80` 显示单组。`theme=dark` 可预览深色。

预览页可切换 Collection / Gallery / History / Settings，设置改动只保存在预览页内存。测试记录使用 10、25、40、50、70 分钟覆盖五档，起止时间分散排列，不写入用户数据库，也不调用保存记录接口。

此入口只在 Vite 开发环境启用，生产构建移除预览入口与模拟数据。不得通过向用户正式 SQLite 注入记录来验收展示。

验证包含：分档前后 1 毫秒、当天归属、午夜重置、0/1/6/20/80/121/400/1440 条记录的封顶堆积、封顶后追加记录不改变布局、20/40/80/110/120 饱和、超过上限仍保留完整数据、稳定缓存、取消计算、不同任务编号的碰撞边界，以及旧检查点默认系列和保存失败不覆盖状态。

小窗随机性：继续复用 cannon-es；取消固定列投放和首颗居中，落点、三维初始角度及轻微初速度由当期种子生成，最终位置由碰撞世界计算。内部随机基准保存在 Snapshot 检查点中，与可编辑设置和 Session 记录分离；旧检查点首次启动时补齐并先保存。当天按本地日期、本周按本地周一起始日派生不同种子，同期重新打开、重启软件或切换范围后切回均复现相同布局。种子参与布局缓存键，跨日期和 day/week 不混用旧布局；封顶后的追加记录仍复用已验证前缀。记录页咖啡罐不使用这项随机策略。

## 计时小窗短句

设置中的自定义短句独立保存，默认关闭且没有预置内容，支持固定选择或每轮随机。随机选择随第一次真正开始专注持久化；暂停、休息、重新打开或恢复不重抽。多条时排除上一轮选中的记录。删除当前短句时显示仍存在的第一条；空列表不显示文字。关闭只隐藏内容。

小窗宽度固定为 360，按关闭短句、仅正文、正文与署名三种结构使用固定高度；正文保持单行，超长时左右往返滚动，不因文本长度继续增高。署名直接展示作者和作品名，不加“节选自”；缺失字段时只展示已有内容。小窗没有箭头、页码、点击或键盘翻页控件。窗口隐藏时停止滚动，重开后从当前句子的开头展示。短句设置与当前轮选择保存在原检查点，旧检查点缺少字段时使用关闭、空列表；不修改历史 Session 或 CSV。短句库在独立页面添加、编辑和选择，支持正文、可选作者和作品名以及添加时的预览；已选条目排在前面，不提供搜索和类型筛选。设置自动保存，不显示保存按钮或成功提示。

小窗范围仅支持 day / week，旧数据默认 day，后端拒绝 month 等值。范围偏好独立合并保存，不覆盖计时、短句或其他偏好。休息待开始、计时、暂停都隐藏豆子，回专注按所选范围恢复。记录页的月份筛选保持不变。

## macOS 菜单栏

专注使用原品牌图标与倒计时；休息使用原咖啡杯与无描边棕色底；超时使用小加号替换图标并显示浅咖啡色底。只按 MM:SS / HH:MM:SS 分为 65pt / 85pt 两档占位，同档三种状态共用数字起点、基线、图标右缘和 3pt 间距；不按当前数字或图标重新居中。背景只填充，不参与布局。数字使用系统等宽数字字体，显示上限 99:59:59 不影响实际计时。
