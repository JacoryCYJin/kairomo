# Kairomo 功能清单与优先级

更新日期：2026-10-26

产品方向：极简计时器 + 轻量记录。主窗口只保留计时和必要操作，设置与统计通过独立入口展开。

排序表示建议优先级，不代表所有功能都已确定开发。状态依据当前实现；“待做”仅表示尚未实现，“可选”需要后续按实际需求决定。

## 建议下一批开发顺序

1. 快捷时长：减少输入操作，选项放在设置里。
2. 提示音设置：提醒清晰但不打断，保留静音。
3. 全局快捷键：减少切换窗口和寻找菜单栏的操作。

以上是候选顺序，不构成开发授权。主计时窗口不增加任务清单、统计面板或说明文案。

## 历史回看规则

- 已完成专注数据持续保存在本机，不按天数自动清理；休息不生成历史记录。
- 日期筛选仅改变展示，全部记录每批展示 50 条，可继续展开，不限制保存数量。
- 周范围为本地时间周一至周日；可查看过去的任意一天、周或月。
- 汇总包含当前会话已确认的有效时间；当前会话在结束前不能修改或删除。
- 跨日会话按有效区间拆分时长；列表显示所选范围内的时长，悬停可查看本轮完整时长。
- 当天图表按小时、本周和本月按天；全部历史按月汇总，跨度超过 24 个月时按年汇总，不丢弃较早数据。
- CSV 导出始终包含全部已保存记录，不受当前筛选影响；进行中的会话结束后进入导出记录。
