# 计时与恢复规则

## 状态

状态为 idle、running、paused，会话种类为 focus 或 break。

- idle → 开始专注 → running/focus。
- running → 暂停 → paused；暂停不累加时长。
- paused → 继续 → running；建立新的有效区间。
- focus → 开始休息：保存专注记录，开始新的 break 会话。
- break → 继续专注：保存休息记录，开始新的 focus 会话，继承任务标题。
- 任意当前会话 → 结束本轮：保存有效时长，回到 idle。
- 取消本轮：确认后丢弃当前 focus 或 break，回到 idle，不生成历史或咖啡豆；保存失败保留原状态。确认携带会话编号，过期确认不能取消新一轮。
- 打开取消确认不会暂停或结束计时；Escape 或“保留本轮”只关闭确认。
- 非法或重复操作返回错误，不重复创建记录。

目标到达仅将提醒标记设为已发送，状态保持 running。不自动进入休息、不重复提醒、不要求先选择延长几分钟。休息到点也继续记录，等待主动恢复专注。

50 + 12 分钟计为同一段 62 分钟。未满目标也保存；暂停和休息不进入专注总量。时长设置仅影响下一段会话。

## 时钟与存储

- 单调时钟用于有效时长，系统时间戳用于记录位置。不是每次界面刷新加一秒。
- 后台约每秒保存检查点并广播；隐藏窗口不影响核心。
- SQLite 完成记录与检查点同一事务提交，避免休息已开始但专注未保存。
- macOS 睡眠事件通过 NSWorkspaceWillSleepNotification 原生通知送入 Rust runtime。睡眠暂停，唤醒不自动恢复；锁屏不等同休息。Windows 暂以调度间隔兜底处理，原生睡眠链路待 Windows 实测完善。
- 如果线程调度或系统事件丢失造成超过 8 秒的间隔，则保守地在最后确认位置暂停，将间隔视为未知，不自动计入。此策略也可能在机器严重卡顿时触发。
- 正常退出先暂停并保存；下次打开手动恢复。
- 异常退出后将正在运行的检查点恢复为暂停，并明确提示未知时间未计入。通常最多损失最后约一秒检查点间隔；存储异常时可能更长。用户可在结束后修正历史记录。
- Rust Instant 不保证各平台睡眠语义一致，因此不把“单调时钟”当作睡眠排除机制。[Rust 原文](https://doc.rust-lang.org/std/time/struct.Instant.html)

## 展示与修正

- 到点前显示剩余时间，到点后显示 +超出时间，另显示本轮累计。
- 按本地日期将有效区间归到每日统计；跨午夜不全部算到开始日期。
- 修正记录允许标题与有效分钟数（0.01–1440），保留原始起止位置与暂停区间，按比例分配新的有效时长，并标记“已修正”。
- 删除需界面确认；导出包含所有历史会话，专注与休息分列 type。CSV 对公式前缀进行处理。
- 本工具记录用户声明的专注，不推断真实认知投入，不因未操作键盘自动暂停。

## 咖啡豆与日历记录

- 每轮已结束的专注获得一颗咖啡豆，未达到目标的短专注也计算；进行中、休息和取消不获得豆。
- 咖啡豆按完成时间归属本地日期。跨午夜的同一轮只获得一颗豆，时长仍按有效区间分摊到实际日期。
- 咖啡豆系列按本轮有效时长分五档：不足 16 分钟浅烘，16–不足 32 分钟中浅烘，32–不足 44 分钟中烘，44–不足 60 分钟中深烘，60 分钟及以上深烘。同档固定豆色，浅色／深色模式分别配色；修正时长同步更新档位。
- 小窗最多六颗为展示摘要，每次新完成替换摘要里最短的一轮；不限制历史获得的豆子总数。
- 记录页以历史会话直接计算豆子，不另存余额。日历选日、周、月、年、自定义及全部范围联动时长、咖啡罐和明细；罐下显示所选范围的真实专注时长，不通过豆数换算；收集区固定大小，完全不能滚动。
- 咖啡罐采用 Matter.js 二维重力、碰撞和摩擦求解静态堆积，仅显示最终位置，不播放下落。罐内目标容量约 80 颗作为初始估计，必须实际填满罐口后才向左右及罐前地面溢出。前景采用独立碰撞平面和分层透视，不重复绘制豆子；整个画面最多展示该范围按完成顺序最先获得的 120 颗。达到展示上限不限制历史记录、完成轮数和真实总时长。
- 相同豆子编号复用最多八组的内存布局缓存；颜色和时长仍取当前记录。隐藏页面暂停未完成的求解，离开页面清理物理世界。展示不参与核心计时和数据保存。
- 日历左右箭头只翻整月，不改变统计筛选；点击日期切换为当天。周从周一开始，月与年以选中日期所属时段为准。
- 自定义起止日期包含结束当天，内部使用本地次日零点作为排他的结束边界，不能用固定 24 小时替代日历日；无效范围不替换已生效的范围。
- 编辑、删除历史记录同步改变相应统计和咖啡豆；导出继续包含全部历史。
