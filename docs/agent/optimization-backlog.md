# Kairomo 优化候选清单

整理日期：2026-11-02。

用途：供规划、审阅与代码执行 Agent 交接。本文是候选清单，文件创建获批不等于下列功能全部获批实现。执行方式见 [执行 Agent prompt](execution-prompt.md)。

## 分工与边界

- 规划／审阅 Agent：核对现状、编写方案、检查执行结果。
- 执行 Agent：重新核对当前代码，对选定事项提出具体方案，获用户确认后修改代码并验证。
- 每批只处理一项已确认任务；不顺手增加功能，不自动提交、推送、合并或发布。
- 保持本地优先、轻量计时定位；不改变既有计时、暂停、睡眠恢复规则，不使用真实用户记录进行破坏性验证。

## 候选事项

优先级是建议，状态是整理时的核对结果，执行前需重新确认。

| 编号 | 优先级 | 事项             | 当前依据                                              | 候选改法与验收重点                                                                                                               |
| ---- | ------ | ---------------- | ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| K01  | 高     | 全局快捷键       | 现有 IPC、设置和桌面依赖中未见全局快捷键接入          | 支持显示／隐藏小窗、暂停／继续；方案明确可配置性、冲突提示、待开始状态行为和退出时注销；不改变计时权威来源                       |
| K02  | 高     | 完整备份与恢复   | 更新前已有 SQLite 备份，设置没有通用备份／恢复入口    | 复用一致性备份能力；明确包含的数据与偏好范围、格式版本、恢复前校验、当前会话处理和失败回滚；先备份再恢复，不直接拿用户数据库试验 |
| K03  | 高     | 分类导出         | CSV 当前列不含分类 ID、名称                           | 提出新版导出格式及旧格式兼容方式；明确归档／删除分类的输出语义；验证中文、引号、换行及公式注入防护                               |
| K04  | 中     | 快捷时长         | 设置通过数值输入调整专注／休息分钟数                  | 提供少量常用值，保留自定义；最近使用值是否保存另行确认；不改变已开始会话的目标时长                                               |
| K05  | 中     | 手动补录         | 已有记录修正接口，未见新增历史记录入口                | 输入时间范围、分类及可选标题；复用重叠和有效时间校验，标记补录来源；不影响当前计时，不伪装为计时器实际采集记录                   |
| K06  | 中     | 提醒设置         | 目前提供通知开关，没有提示音选择、试听入口            | 提供测试提醒、短提示音试听和静音；区分应用设置与系统通知权限；不承诺绕过系统静音或勿扰模式                                       |
| K07  | 先测量 | 大量历史记录性能 | 列表每批展示 50 条，但存储查询及 IPC 返回完整记录集合 | 用隔离模拟数据测量读取、筛选、时间轴和汇总耗时；有瓶颈再决定范围查询、分页或缓存；保留跨日、分类筛选、全部导出的正确性           |
| K08  | 维护   | 更新功能路线图   | 旧路线图仍将分类等已实现内容列为未实现                | 重新核对每一项状态，区分分类与真正的待办任务；不把候选功能标成已批准或已完成                                                     |

建议顺序：K01 → K02 → K03 → K04，其余按实际使用反馈决定。该顺序不构成实现授权。

## 当前不纳入

- 云同步、手机端、复杂项目／任务管理、应用与网站屏蔽。
- 全面重设计界面、增加主题、替换架构或跨仓库复用。
- 更新版本、创建标签、上传安装包与发布更新通道。

## 每项交付记录

执行 Agent 对选定事项报告：编号、最终范围、涉及文件、实际行为、验证命令与结果、未验证内容，以及供审阅 Agent 检查的风险和差异。未通过或未验证的事项不勾选完成。
