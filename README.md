# Kairomo

**Time for what matters.**

Kairomo 是一款轻量的 macOS 专注计时工具，陪你安排专注与休息，用一罐咖啡豆记录每一次投入。

[下载 macOS Beta](https://github.com/JacoryCYJin/kairomo/releases) · [反馈问题](https://github.com/JacoryCYJin/kairomo/issues)

## 按自己的节奏专注

设定一个目标，开始眼前的事情。

你可以在到点后继续专注，结束时记录完整的实际时长；也可以选择到点结束，提醒自己休息。暂停的时间不会计入专注记录。

计时常驻菜单栏，需要时展开小窗，就能开始、暂停或切换休息。

## 让投入看得见

每完成一次专注，就收获一颗咖啡豆。

不同的专注时长对应不同深浅的烘焙颜色。打开记录日历，看看某一天、某一周，或一段时间里积累的那一罐咖啡豆。

## 休息，像喝完一杯咖啡

进入休息后，咖啡色的波浪随着剩余时间慢慢下降。

杯子喝完，休息结束。下一轮专注由你亲手开始。

## 回看自己的时间

按日、周、月、年或自定义日期查看专注记录与累计时长。你可以修改记录名称、修正时长，也可以将记录导出为 CSV。

## 记录留在自己的电脑里

无需注册账户，计时和历史回看可以离线使用。专注记录保存在本机，检查更新时才需要联网获取版本信息。

支持简体中文、英文，以及浅色和深色外观。

## 获取 Kairomo

目前提供 Apple Silicon Mac 的 Beta 安装包。下载安装后，将 Kairomo Beta 拖入“应用程序”即可使用。

当前 Beta 尚未经过 Apple 公证，首次打开可能需要在系统“隐私与安全性”中允许运行。

[查看下载与版本说明](https://github.com/JacoryCYJin/kairomo/releases)
